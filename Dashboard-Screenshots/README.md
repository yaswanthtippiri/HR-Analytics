
# HR Analytics Dashboard – Screenshots

## Overview
This folder contains screenshots of the HR Analytics dashboard developed using Tableau Public.

## Dashboard Preview

The dashboard provides an overview of employee attrition and workforce trends through interactive visualizations.

## Key Performance Indicators (KPIs)
- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Age: 37

## Visualizations
- Attrition by Gender
- Department-wise Attrition
- Employee Count by Age Group
- Job Satisfaction Rating
- Education Field-wise Attrition
- Attrition Rate by Gender across Age Groups
