# HR Analytics – Employee Attrition Analysis

## Project Overview
The HR Analytics project focuses on analyzing employee data to understand workforce trends and identify the key factors influencing employee attrition.

Using SQL Server and Tableau Public, I analyzed employee information and developed an interactive dashboard to present meaningful HR insights that can support data-driven decision-making.

## Project Objectives
- Analyze overall employee attrition.
- Identify department-wise attrition trends.
- Understand attrition patterns across age groups and gender.
- Evaluate job satisfaction ratings.
- Analyze education field-wise attrition.
- Present key HR metrics through an interactive dashboard.

## Tools & Technologies
- **SQL:** SQL Server Management Studio (SSMS)
- **Data Visualization:** Tableau Public
- **Data:** CSV, Microsoft Excel

## Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Total Employees | 1,470 |
| Attrition Count | 237 |
| Attrition Rate | 16.12% |
| Active Employees | 1,233 |
| Average Age | 37 |
