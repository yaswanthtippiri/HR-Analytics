# HR Analytics Dataset

## Overview
This folder contains the HR dataset used for the HR Analytics project. The dataset provides employee-related information to analyze workforce trends and employee attrition.

## Dataset Details
- **File Name:** HR_Data.csv
- **Total Records:** 1,470 employees
- **Total Columns:** 39
- **File Format:** CSV

## Key Analysis Areas
- Employee attrition
- Department-wise employee distribution
- Gender and age-group analysis
- Job satisfaction
- Education field-wise attrition
- Employee workforce trends

## Data Usage
The dataset was used for data analysis and visualization using SQL Server and Tableau Public.

## Tools Used
- SQL Server Management Studio (SSMS)
- Tableau Public
- Microsoft Excel

## Note
This dataset is included for educational and analytical purposes as part of the HR Analytics project.
