
# HR Analytics – SQL Analysis

## Overview
SQL-based analysis of employee attrition and workforce trends using Microsoft SQL Server.

## Database Details
- Database: HR_Analytics
- Table: dbo.HR_Data
- Total Records: 1,470
- Total Columns: 39
- Tool: Microsoft SQL Server Management Studio (SSMS)

## Analysis Performed
1. Overall employee count and attrition metrics
2. Department-wise attrition analysis
3. Gender-wise attrition analysis
4. Job role and marital status analysis
5. Employee satisfaction analysis
6. Education field analysis
7. Age group analysis
8. Salary and experience analysis
9. Work-life balance analysis

## SQL Concepts Used
- SELECT and WHERE
- GROUP BY and HAVING
- Aggregate Functions
- CASE Statements
- CTEs
- Subqueries
- Window Functions
- RANK, DENSE_RANK and ROW_NUMBER

## SQL Script
The file `HR_Analytics_Analysis.sql` contains the queries used for this project.

## Key Findings
- Total Employees: 1,470
- Employee Attrition: 237
- Active Employees: 1,233
- Overall Attrition Rate: 16.12%

## Objective
To analyze employee attrition patterns and identify workforce trends that can support better HR decision-making.
